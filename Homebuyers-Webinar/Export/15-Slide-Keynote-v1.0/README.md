# 19-Slide Keynote v1.0

Browser-based visual presentation for `The Homebuyer's Playbook`.

Open `index.html` in a browser and use the left/right arrow keys to move through the deck. On slide 2, press the spacebar once to fly in the six roadmap topics; press space again to advance. Navigation controls appear on hover or keyboard focus.

## Notes

Live in-deck calculator modules are included for rent vs buy, payment, affordability, monthly budget, cash to close, APR comparison, and buydown break-even. Loan program and down-payment sections use educational comparison controls, not eligibility promises.

Interactive Layer v1 includes:

- Spacebar-triggered six-topic roadmap reveal.
