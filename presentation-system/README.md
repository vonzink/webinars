# Mountain State Financial Group Presentation System

This is a standalone keynote-style web presentation, not a PowerPoint template.

Open `index.html` in a browser and use left/right arrow keys to move through the slides. The system includes:

- Master slide
- Title slide
- Section divider
- Content slide
- Two-column layout
- Image-heavy layout
- Comparison layout
- Calculator layout
- Timeline layout
- Infographic layout
- Quote slide
- Closing slide
- Question slide
- CTA slide
- Reference slide
- Thank-you slide

## Design Language

The signature visual device is a topographic trust grid: Colorado contour-line imagery that also reads like amortization and homeownership progress. The deck uses white space, large editorial type, restrained green, transparent calculator panels, and simple financial diagrams.

Brand assets live in `assets/brand/`:

- `msfg-home-loans-horizontal.png`
- `msfg-home-loans-stacked.png`
- `seth-headshot.png`
- `seth-contact-qr.png`
- `graphics-standards-manual.pdf`

- Raleway ExtraBold caps for display/brand treatment
- Source Sans Pro for support text
- `#ffffff`, `#404041`, `#104547`, `#2f5e4c`, `#4b7b4d`, `#6a9b48`, `#8cc63e`
