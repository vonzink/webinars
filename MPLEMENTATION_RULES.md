# PURPOSE

This document defines the implementation standards for every file, asset, slide, graphic, animation, illustration, and component in this project.

The objective is to produce a presentation that can be maintained, expanded, and reused for years.

Every asset should be considered part of a reusable presentation system—not a one-time PowerPoint.

# FILE NAMING

Always use:

Title-Case

Examples

```

Mortgage-Payment-Breakdown.svg

Loan-Comparison-Cards.pptx

Closing-Cost-Timeline.svg

Rent-vs-Buy-Illustration.ai

```

Avoid

```

slide2FINALv5.png

image.png

newgraphic.svg

graphic-final-final2.png

```

---

# GRAPHICS

Always create vector graphics whenever possible.

Preferred formats

SVG

PDF

AI

EPS

Only export PNG when transparency is required.

Never rasterize illustrations unnecessarily.

---

# IMAGES

Preferred

WebP

PNG

High-quality JPG

Minimum resolution

1920 pixels wide

Never upscale low-resolution images.

---

# ICONS

Icons must come from the same icon family.

Preferred styles

Outlined

Rounded

Modern

Minimal

Avoid

Emoji

Clipart

3D icons

Skeuomorphic graphics

---

# SLIDES

Each slide should contain

One objective

One key message

One primary visual

One supporting graphic

Speaker notes

Transition notes

Estimated presentation time

Audience interaction opportunities

---

# POWERPOINT

Every slide should be editable.

Never flatten text into images.

Every object should remain editable.

Charts should remain editable.

Icons should remain editable.

Illustrations should remain editable.

---

# SAFE MARGINS

Keep all important content within presentation-safe margins.

Avoid placing text too close to edges.

Maintain consistent spacing throughout the presentation.

---

# ALIGNMENT

Everything aligns to a consistent grid.

Never manually eyeball placement.

Use equal spacing throughout.

---

# SPACING

Use an 8-point spacing system.

Examples

8

16

24

32

40

48

64

96

128

Avoid random spacing values.

---

# SHADOWS

Subtle only.

Never use harsh drop shadows.

Never use glowing effects.

Never use bevels.

---

# ROUNDED CORNERS

Use consistent corner radii.

Suggested

12px

16px

24px

Do not mix random corner sizes.

---

# COLOR USAGE

Green is an accent.

Not a background color.

White should dominate.

Dark green anchors.

Bright green highlights.

---

# ACCESSIBILITY

Minimum contrast ratio

WCAG AA or better

Avoid color-only communication.

Icons should reinforce meaning.

---

# CALCULATOR INTEGRATION

Every calculator slide should contain

Introduction

Problem statement

Live demonstration indicator

Key takeaway

Transition back into presentation

The audience should understand why the calculator matters before it appears.

---

# ANIMATIONS

Animations should be consistent.

Preferred

Fade

Appear

Morph

Zoom

Wipe

Duration

0.3–0.6 seconds

Avoid

Bounce

Spin

Flash

Random entrances

Sound effects

---

# DIAGRAMS

Create custom diagrams whenever possible.

Preferred

Flowcharts

Timelines

Process diagrams

Decision trees

Relationship maps

Avoid generic SmartArt.

---

# INFOGRAPHICS

Every infographic should tell a story.

Not decorate a slide.

Keep labels minimal.

Use icons over text where appropriate.

---

# SPEAKER NOTES

Every slide should include

Purpose

Talking points

Story examples

Audience questions

Common misconceptions

Transition

Estimated duration

---

# QUALITY CONTROL

Before approving any slide verify

✓ Grammar

✓ Alignment

✓ Contrast

✓ Typography

✓ Branding

✓ Compliance

✓ Animation

✓ Accessibility

✓ Presentation flow

✓ Visual balance

---

# COMPLIANCE

Whenever presenter information appears

Include

Name

Title

NMLS

Company

Required licensing

Equal Housing logo when appropriate

Never guarantee approval.

Never promise interest rates.

Never make misleading claims.

---

# VERSION CONTROL

Maintain version history.

Do not overwrite completed assets.

Use semantic versions.

Examples

Presentation-v1.0

Presentation-v1.1

Presentation-v2.0

---

# REUSABILITY

Whenever creating a graphic ask

Can this be reused later?

If yes

Store it as an independent asset.

Do not embed reusable graphics inside a single slide.

---

# FINAL DESIGN TEST

Every slide must pass the following test.

Would Apple present this?

Would Microsoft Build present this?

Would TED present this?

Would a Fortune 500 company use this?

Would attendees photograph this slide?

Does this increase trust in Mountain State Financial Group?

If any answer is no

Redesign the slide.

---

# PROJECT MISSION

The goal is not to build a presentation.

The goal is to build the definitive educational platform for first-time homebuyers.

Every asset should contribute to that mission.
