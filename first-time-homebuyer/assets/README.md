# assets/

Raw source files. **Nothing here is delivery-ready** — exports go to `../final/`.

## What belongs here

```
assets/
  video/        Recorded takes, B-roll, screen captures of the calculators
  audio/        Intro/outro beds, recorded VO
  fonts/        Licensed font files (see ../branding/fonts.md)
  logos/        Official MSFG brand assets when they arrive
  photos/       Licensed or original photography, full resolution
  deck/         The working presentation file (Keynote/PPT/Figma)
  exports/      Intermediate exports — not final
```

## Conventions

- **Never edit in place.** Version by filename: `deck-v4.key`, `deck-v4.1.key`
- Photography at full resolution — **minimum 2560px wide** for full-bleed
- Keep license documentation alongside any licensed asset
- Screen recordings of the calculators are the source for the fallback slides —
  🔁 **re-record whenever calculator output changes**
