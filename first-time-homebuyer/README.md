## The five design rules

1. **One house, one loan, all 38 minutes.** $450,000 / 5% down / $427,500 /
   30-year fixed — and the buyers sit at **exactly 45.0% DTI, approved at the
   ceiling**, so the affordability module has an argument instead of a fact.
2. **The Gap is the antagonist.** Named at 1:20, closed module by module, and the
   last line of the webinar is that it's closed.
3. **Every module ends in a portable artifact** — a rule, threshold, or checklist
   they can execute without me.
4. **The calculators teach; they don't pitch.**
5. **No urgency, ever.** No "rates are going up." No scarcity. Two refusals are
   made on camera at 2:00, which makes breaking them visible.

**The word cap is a rule, not a guideline.** v4 died of a 7,000-word script in a
40-minute container. If a rehearsal runs over, cut sentences — don't talk faster.

2. Confirm CHFA / down payment assistance program status **on the date of delivery**.
3. Compliance pass — `prompts/05-compliance-review.md`.
4. Test all three calculators; confirm fallback slides are current.
5. Confirm NMLS IDs and Equal Housing Lender mark are on slides 001, 070, and every
   slide containing a number.

## Compliance posture

This is educational content. It contains **no rate quotes, no offers, and no
commitments to lend.** All figures are labeled hypothetical. Advertising rules
(TILA/Reg Z trigger terms, UDAAP, state licensing) are addressed in
`prompts/05-compliance-review.md`, which must be run before each delivery and
re-run whenever a number changes.
