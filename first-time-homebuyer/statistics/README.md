## How to use this folder

One file per delivery date: `verified-YYYY-MM-DD.md`. Never overwrite a prior
verification — the history is how you notice a number drifting.

Template:

```markdown
# Verification — [DELIVERY DATE]
Verified by: [name] · Date run: YYYY-MM-DD

## Tier 1
| # | Claim | Figure found | Source | Published | URL | Status |
|---|---|---|---|---|---|---|
| 1 | FTB median down payment | __% | NAR Profile | ____ | ____ | ✅ / ⚠️ directional / ❌ cut |

## Changes since last verification
- [what moved, and which slides it affects]

## Slides requiring edits before delivery
- [ ] Slide ___ — [what changes]

## Items cut for this delivery
- [claim] — could not verify. Using directional phrasing on slide ___.
```

## The rule that matters most

**A cut statistic costs nothing. A wrong one costs the entire webinar.**

If a number can't be verified in time, use the directional phrasing in
`../knowledge/statistics.md` § *"How to speak Tier 1 if unverified."* Every core
argument in this deck was deliberately built to survive without a precise figure —
the breakeven lesson, the 20% myth, and the shop-multiple-lenders lesson all work
on structure alone.
