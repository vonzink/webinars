## The spine

Four fears, in the order the audience actually feels them:

1. **I don't know what happens.** → Module 2
2. **I'm going to overextend and regret it.** → Module 3
3. **I don't have enough money.** → Module 4
4. **I'm being taken advantage of and I can't tell.** → Modules 5–6

Credit (7), builder (8), mistakes (9) are supporting material. The close (10) is
homework first, ask second.
