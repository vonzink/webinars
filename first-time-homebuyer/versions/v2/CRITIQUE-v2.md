# Critique Pass 2 — against v2

Reviewer lens: *"This is now a good webinar. What would make it the one every
other mortgage company wishes they'd built?"*

## Verdict: Good structure. Still not a masterclass. Five gaps.

### Gap 1 — Every module uses different example numbers

v2 invents fresh numbers per module: a $400k house here, a $375k house there, a
$500k example for APR. That is the single most common reason educational content
feels slippery — the audience has to rebuild the mental model every module and
never accumulates fluency.

**Fix — the biggest single improvement in this deck:** One canonical example
carried from minute 3 to minute 40. One couple. One house. One loan.
$450,000 Colorado purchase, 5% down, $427,500 loan, 30-year fixed. Every module
adds a layer to *the same numbers*. By minute 30 the audience knows this loan
personally and can predict what happens next — which is what fluency actually
feels like. Locked in `references/canonical-example.md`.

### Gap 2 — Teaching *at* instead of teaching *toward a transferable skill*

v2 explains APR well. It does not leave the audience with a repeatable procedure.
Understanding decays. Procedures don't.

**Fix:** Every module must terminate in a portable artifact — a rule, a threshold,
or a checklist the audience can execute without me:
- Process → the 9-stage map, printable
- Affordability → *The Number* exercise + the payment-shock test
- Programs → a 5-question decision tree
- Rates → "half a point ≈ $140/mo ≈ $23,000 of house" + the breakeven rule
- Loan Estimate → the 60-second two-lender comparison method (Section A only)
- Credit → the 45-day window + the do-not-do list
- Builder → 12 questions to ask, printable

### Gap 3 — Objections are never named out loud

The audience is silently arguing with me the entire time: *"He's a broker, of
course he says use a broker." "Everyone says rates will drop." "My cousin said
FHA is bad."* v2 never surfaces these, so they never resolve.

**Fix:** Pre-empt six objections explicitly, including the two that cut against
my own interest (renting is sometimes correct; sometimes the builder's lender
genuinely wins). Naming the objection before the audience thinks it is the
single highest-trust move available. Captured in `knowledge/common-objections.md`.

### Gap 4 — One Q&A block at the end wastes the best engagement signal

**Fix:** Three 45-second "Ask Me Anything" breaks at minutes 13, 24, and 33,
seeded with a planted question if chat is quiet. Plus a live Q&A after minute 40.
Questions asked mid-stream are better questions than questions saved up.

### Gap 5 — The CTA is a single ask, so it converts only the ready 5%

A one-size CTA ignores that this room spans "browsing Zillow at midnight" to
"under contract Friday."

**Fix:** Three-tier CTA matched to the Poll 1 distribution, plus an unconditional
offer with no strings: *send me any Loan Estimate from any lender and I'll mark it
up for free, even if I never earn your business.* That offer is the proof of the
whole thesis.

### Also fix
- Slide count 66 → 70 for the added artifacts.
- Compliance layer was implicit. Make it explicit on every slide with a number.
- Add a "what I'm not going to do" slide in the first 90 seconds (no rate quotes,
  no scarcity, no "rates are going up, act now").

→ Produces **v3**.
