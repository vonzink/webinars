## THE RULE

**Every Loan Estimate shown must use fabricated data and be visibly watermarked
SAMPLE.** Never a real consumer's document, even redacted, even with permission.
Redaction fails. Don't start from a real one.

Build the samples from `../../references/canonical-example.md` so the numbers are
consistent with the rest of the deck.

## Build notes

- 🔴 **Verify the current CFPB form layout before building.** The form has been
  revised since 2015 — an outdated graphic teaches the wrong boxes.
- Sample figures must tie to the canonical example: $427,500 loan, 30-year fixed,
  6.500%, and the Section A values from Story 5 (~$1,300 vs. ~$7,700).
- Type must remain readable when the page is shown at slide scale — build at high
  resolution and crop to the relevant region rather than shrinking the whole page.
- Watermark: diagonal, **SAMPLE**, ~15% opacity, unmistakable but not obstructive.

## Compliance

- No lender name, logo, or identifying detail on any sample
- No real consumer data of any kind
- Story 5 is a composite; the documents illustrate it, they don't reproduce it
